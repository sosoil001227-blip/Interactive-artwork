# masks

아이언맨·가오나시·보·슈퍼 마리오·코난·짱구·코렐라인의 카메라 인터랙션입니다. 예제 8~12번 상단의 **13 마스크** 버튼으로 열 수 있습니다.

프로젝트 루트에서 실행합니다.

```sh
npm ci
npm run dev:example13
```

공용 서버 주소는 [https://localhost:5174/example-13/](https://localhost:5174/example-13/)입니다. 기존 서버가 켜져 있다면 주소를 바로 열 수 있습니다.

- 최종 QA까지 생략: 브라우저에서 실제 클릭·화면 전환, 화면 크기별 메뉴 배치, 전체 빌드·테스트. 개발·미리보기 서버는 실행하지 않음.

독립 실행이 필요하면 `example-13` 안에서 `npm ci`와 `npm run dev`를 실행합니다. 독립 실행 주소는 [http://localhost:5175/](http://localhost:5175/)입니다.

1. **아이언맨**, **가오나시**, **슈퍼 마리오**를 선택하고 카메라를 켭니다. 화면 정면을 잠시 본 뒤 고개를 내렸다가 정면으로 돌아오면 마스크가 장착됩니다.
2. **아이언맨**은 일곱 개의 파츠가 순서대로 결합하고, 장착 후에는 양쪽 눈에서 붉은 레이저가 나옵니다.
3. **가오나시**를 장착하고 입을 벌리면 마스크의 입에서 금이 쏟아집니다. 입을 다물면 더 이상 금이 나오지 않습니다. 이 옵션에서는 작은 새와 회색 친구가 화면을 날아다닙니다.
4. **해제**와 **초기화**로 마스크를 벗을 수 있습니다. 카메라 없이 **체험 시연**을 누르면 각 마스크의 효과를 볼 수 있습니다. 카메라를 사용하는 중에는 **장착** 버튼으로도 장착할 수 있습니다.

## 슈퍼 마리오

1. 고개를 내렸다가 정면으로 돌아오면 빨간 M 모자·동그란 코·수염이 사방에서 회전하며 날아와 각각 하나씩 얼굴에 붙습니다.
2. 얼굴 양옆에 양손을 들고 손바닥을 카메라로 향해 열 손가락을 펴면 흰 장갑이 위에서 내려와 손에 붙습니다. 장갑은 손가락의 움직임을 따라갑니다.
3. 고개를 왼쪽·오른쪽·왼쪽으로 흔들면 가운데 물음표가 있는 벽돌 줄이 내려옵니다.
4. 물음표 벽돌을 아래에서 위로 손끝이나 주먹으로 치면 동전이 쏟아지고 짧은 게임풍 효과음이 납니다. **효과음 ON/OFF**로 소리를 조절합니다. 효과음은 Web Audio로 합성합니다.
5. **체험 시연**은 카메라 없이 장착·장갑·벽돌·동전 순서를 보여 줍니다. **초기화**하면 장갑·벽돌·동전 수를 함께 초기화합니다.

마리오는 양손을 볼 수 있도록 카메라 영상을 자르지 않고 전체 표시합니다. 손 인식 전에는 손가락 가이드와 각 손의 펼친 손가락 수, 화면 왼쪽에는 인식한 손·손가락 수가 표시됩니다. 3D 손 좌표로 손가락 펼침을 계산하고, 한 손가락의 불확실한 좌표와 180ms 이내의 짧은 인식 누락을 허용합니다. 물음표 벽돌은 영상 내부에 배치하며 위로 치는 동작만 판정하고 연속 타격 사이에 400ms 간격을 둡니다.

- 카메라가 연결되면 마리오 화면의 높이를 원본 영상의 가로세로 비율에 맞춰 전체 영상을 여백 없이 표시합니다.

## 아이언맨 건틀릿 · 손 외곽 가림 보강

손등을 보였다가 손바닥으로 돌려 건틀릿 장착을 마치면, 기존 금속 파츠 아래에 불투명한 장갑층을 함께 그립니다. 손바닥·엄지 밑부분·손 옆면·손목은 여유 폭을 둔 외곽으로 덮고, 다섯 손가락은 관절 사이와 손끝까지 이어지는 개별 장갑층으로 덮습니다. 손가락이 짧게 투영돼도 장갑 폭을 줄이지 않으며, 금색·빨간색 파츠의 폭과 손끝 마감도 넓혔습니다. 벌린 손가락 사이는 손가락별 형상을 유지합니다.

### 아이언맨 외곽 추가 보정 · 2026-11-22

- 기본 손가락 폭을 약 20~25% 늘리고 손끝의 폭 감소를 완화. 금속 파츠의 폭과 손끝 덮개를 추가 확대하고 손바닥·손목의 여유 폭도 보강.

## 추적과 AR 확장

- `tracking.ts`의 `TrackingFrame`은 좌우 반전 전 영상 크기, 타임스탬프, 3D 얼굴 랜드마크와 얼굴 변환 행렬을 전달합니다. Worker에서 [MediaPipe Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker)를 실행합니다. 마스크가 보일 때는 추론에 쓴 영상과 랜드마크를 함께 표시합니다.
- `gesture.ts`는 얼굴 변환 행렬에서 피치를 읽고 정면에서 벗어났다 돌아오는 동작을 판정합니다. `animation.ts`는 파츠별 출발 시점과 장착·해제 상태를 다룹니다.
- `rig.ts`의 각 파츠 표면은 정규 얼굴 메시의 삼각형에 결합되어 있습니다. `resolveRig`는 추적 데이터에서 파츠별 3D 정점과 표면을 계산합니다. `art.ts`에서 이 출력을 미러 카메라 화면에 투영합니다. AR 렌더러에서도 같은 파츠와 애니메이션을 쓸 수 있으며, 기기 카메라 보정값과 AR 세션 포즈는 통합할 때 적용합니다.
- `spirit.ts`는 입술 랜드마크 간격으로 입 벌림을 감지하고 금 조각을 움직입니다. `companions.ts`는 두 친구의 비행을 그립니다.
- `canonical.ts`의 좌표와 삼각형은 Google MediaPipe의 [Canonical Face Model](https://github.com/google-ai-edge/mediapipe/blob/master/mediapipe/modules/face_geometry/data/canonical_face_model.obj)을 정규화한 것입니다. 출처 프로젝트는 Apache License 2.0을 사용합니다. 자세한 조건은 [MediaPipe 라이선스 사본](MEDIAPIPE-LICENSE.txt)에 있습니다.

## 옵션 4 · 코난

1. 네 번째 **코난**을 선택하고 카메라를 켭니다. 얼굴과 목, 상반신을 화면에 보여 주세요.
2. 손가락을 눈 사이에 가져온 뒤 안경을 올리듯 위로 밀면 검은 안경이 착용됩니다.
3. 목 아래 매무새를 손으로 잠깐 만지면 빨간 리본과 파란 재킷·흰 셔츠가 나타납니다. 안경 제스처와 목 매무새 제스처는 어느 순서로 해도 됩니다.
4. 착용을 마친 뒤 **실제 왼손**의 검지만 펴 카메라를 향해 가리킵니다. 나머지 손가락은 가볍게 접습니다. 손가락이 렌즈 쪽을 향하는 깊이 방향과 짧은 유지 시간을 함께 판정합니다.
5. 사용자 뒤에 푸른 번개가 치고, 빨간 띠·흰 자막창이 있는 사건반장풍 화면이 약 10초 동안 나타납니다. 자막과 한국어 합성 나레이션은 다음 문장으로 재생됩니다.

   > 내 이름은 코난, 탐정이죠. 범인은 바로 당신이야! 진실은 언제나 하나!

6. **나레이션 ON/OFF**로 목소리와 짧은 번개 효과음을 조절합니다. 장면이 끝난 뒤 손을 내렸다가 다시 지목하면 재생됩니다. **초기화**는 의상·안경·연출·음성을 모두 초기화합니다. **체험 시연**으로 카메라 없이 전체 순서를 볼 수 있습니다.

코난 화면은 카메라의 원본 가로세로 비율을 따릅니다. 안경은 얼굴을 따라가고, 재킷은 어깨·팔 관절과 인물 윤곽에서 측정한 좌우 폭에 맞춰집니다. 리본의 위치와 크기는 목 아래 지점과 목 너비를 따라갑니다. 손은 같은 카메라 프레임에서 복원해 의상 앞에 보이도록 합니다.

나레이션은 macOS의 한국어 시스템 음성 Eddy로 생성한 로컬 WAV 3개를 사용합니다. 대사별 재생 시점은 0.45초·3.30초·5.90초이며, 자막도 같은 시점으로 바뀝니다. 파일은 `src/assets/conan/`에 있으며, 코난 성우나 방송 원본 음성을 사용하지 않았습니다. 왼손 구분은 설치된 MediaPipe SDK의 `HandLandmarkerResult.handedness` 규칙에 따라 반전 전 영상의 사용자 왼손을 사용합니다.

## 옵션 5 · 짱구의 크레용

1. 다섯 번째 **짱구**를 선택하고 **카메라 켜기**를 누릅니다. 참고 이미지의 빨간 베레모·파란 그림옷을 입은 작은 짱구가 카메라 영상의 왼쪽 아래에서 등장합니다.
2. 짱구가 영상 귀퉁이를 들추면 종이 뒷면과 숨겨진 크레용이 보입니다. 크레용을 찾은 짱구가 팔을 들어 보여 주고, 화면은 다시 제자리로 돌아옵니다.
3. 왼손이나 오른손을 짱구가 내민 크레용의 점선 원에 가져가 잠깐 기다립니다. 손끝·엄지·손바닥 중 하나가 원 안에 머무르면 크레용을 받습니다. 얼굴이 아직 보이지 않아도 받을 수 있습니다.
4. 엄지와 검지를 모아 가이드 안을 문지르면 칠해지고, 벌리면 멈춥니다. **살구색**으로 볼과 귀를 포함한 짱구의 얼굴 전체를 채웁니다. **검정**으로 머리, 굵은 눈썹, 큰 눈, 입을 그릴 수 있습니다. 그리는 중 손가락을 벌린 뒤 반대 손을 모아 바꿔 그릴 수 있습니다.
5. **빨강**으로 어깨와 상반신 윤곽을 따라 그려지는 옷 가이드를 칠합니다. 카메라에 양쪽 어깨와 상반신을 보여 주세요. 얼굴 그림은 얼굴에, 옷은 몸에 붙어 움직입니다. 크레용을 건넨 짱구는 아래에서 좌우로 이동하며 엉덩이 춤을 춥니다.
6. **그림 지우기**는 크레용을 든 채 그림만 지웁니다. **초기화**는 크레용 찾기부터 다시 시작합니다. 카메라를 켜기 전 **체험 시연**으로 등장·화면 들추기·크레용 전달·그리기·춤을 미리 볼 수 있습니다.

캐릭터와 크레용·화면 말림 효과는 참고 이미지의 색과 형태를 바탕으로 Canvas에 그립니다. 실시간 영상은 전체를 좌우 반전해 표시하며, 얼굴이나 몸의 인식이 끊기면 해당 그림을 숨기고 다시 인식되면 복원합니다. 손이 사라지거나 갑자기 이동한 구간은 선으로 연결하지 않습니다. 탭이 숨겨지면 추적을 중지하고 그림과 크레용 상태는 유지합니다. 동작 줄이기 설정에서는 화면 들추기를 생략하고 크레용을 바로 제시하며, 춤의 좌우 이동·흔들림을 멈춥니다.

## 옵션 6 · 코렐라인

1. **코렐라인**을 선택하고 카메라를 켭니다. 얼굴과 양쪽 어깨가 보이는 상태에서 잠깐 정면을 본 뒤, 고개를 아래로 내렸다가 다시 정면을 바라봅니다. 목과 어깨, 팔을 따라 노란 우비가 나타납니다.

우비는 자세 랜드마크와 같은 프레임의 인물 분리 마스크를 이용해 입힙니다. 인물 분리 결과가 없는 순간에는 영상 가운데 인물이 보이도록 소용돌이를 가장자리에 표시합니다. 동작 줄이기 설정에서는 고정된 소용돌이와 단추 눈 인형이 나타납니다.

옵션 2의 제목과 버튼 이름은 **가오나시와 보**입니다. 옵션 안의 **가오나시 / 보** 버튼으로 캐릭터를 선택합니다. 가오나시의 장착·입 벌리기·금 쏟기·동행 캐릭터 동작은 기존 방식을 유지합니다.

### 보로 변하기

1. **보**를 고르고 카메라를 켭니다. 입을 다물고 볼에 힘을 뺀 채 정면을 약 1초 바라보면 기본 표정을 맞춥니다.
2. 양 볼에 공기를 채워 빵빵한 상태를 약 3초 유지합니다. 양쪽 볼의 폭·깊이·둥글어지는 변화와 표정 점수를 함께 사용하며, 입 벌리기·웃음·고개 회전·한쪽 볼만 움직이는 동작을 구분합니다.
3. 실제 카메라 얼굴의 볼이 조금씩 부풀고 붉어집니다. 실제 얼굴 영상의 색과 명암이 단순해지면서 구도와 비율이 서서히 바뀌고, 빨간 턱받이에 흰 **坊** 글씨가 있는 앉은 모습의 2D 보로 이어집니다.
4. 전환이 끝나면 원본 카메라 영상의 표시 비중은 0이 되고, 전체 보 캐릭터와 반투명 빨간 배경이 남습니다. 배경의 흰 원형 낙서 선은 캐릭터 뒤에서 천천히 회전합니다.
5. 변신 도중 볼의 힘을 빼면 천천히 되돌아갑니다. 변신을 마친 뒤에는 보의 모습이 유지되며 **초기화**로 원래 카메라 모습과 표정 맞추기 단계로 돌아갑니다. 카메라를 켜기 전 **체험 시연**도 사용할 수 있습니다.

실제 영상의 볼 변형·붉어짐·색 단순화는 WebGL로 처리하며, 사용할 수 없으면 작은 Canvas 영상의 픽셀 처리로 전환합니다. 참고 이미지의 보와 붉은 바탕·흰 선은 Canvas로 그립니다. 동작 줄이기 설정에서는 볼 확대·화면 구도 이동과 배경 회전을 생략하고 색 변화와 전체 장면의 전환을 유지합니다.

표정 점수 출력은 보 모드에서만 [MediaPipe Face Landmarker의 `outputFaceBlendshapes` 옵션](https://developers.google.com/edge/api/mediapipe/js/tasks-vision.facelandmarkeroptions)을 켜서 받습니다. 볼 부풀리기 점수 하나에만 의존하지 않고, 개인별 중립 표정에 대한 양쪽 볼의 상대 변화도 함께 사용합니다.
