# 고무 인간 · Example 12

11번과 같은 루트 Vite 서버의 **https://localhost:5174/example-12/** 에서 실행합니다. 기존 서버가 켜져 있으면 주소만 여세요. 서버 실행은 사용자가 직접 합니다.

```sh
# 프로젝트 루트에서 사용자가 실행
npm run dev
# 또는 12번을 바로 여는 같은 서버의 별칭
npm run dev:example12
```

1. 12번 페이지를 열면 소개·대기 화면 없이 카메라 연결과 얼굴·손 추적을 자동으로 시작합니다. 브라우저의 카메라 접근 요청이 뜨면 허용하세요. 카메라 영상은 추적 모델을 준비하는 동안에도 바로 표시됩니다.
2. 화면 속 얼굴의 원하는 지점에 엄지와 검지를 겹쳐 **Pinch**합니다. 이마·관자놀이·양볼·턱까지 얼굴 전체에서 집을 수 있습니다. 실제 피부에 손가락을 댈 필요는 없습니다.
3. 집은 얼굴 지점이 손끝에 고정됩니다. Pinch를 유지한 채 손을 움직이면 처음 잡은 같은 지점이 고무처럼 늘어나 따라갑니다. 얼굴 밖에서 먼저 Pinch해도 그 상태로 얼굴에 닿으면 잡힙니다. 손가락을 벌리면 관성과 탄성으로 돌아옵니다. 얼굴 밖에서는 임의의 얼굴 지점을 잡지 않습니다.
4. 한 손의 손목을 돌려 비틀거나, 양손으로 집고 벌리거나 엇갈려 회전하면 얼굴이 둥근 스크류 형태로 꼬입니다. 손을 모두 놓으면 비틀림도 복원됩니다.

**손끝 표시**, **원래대로**, **카메라 종료**를 지원합니다. 엄지·검지와 그 사이의 작은 점을 기본적으로 표시하고, 잡히면 가운데 점이 연두색으로 커집니다. 표시를 끌 수 있으며 연결선·얼굴 윤곽선은 그리지 않습니다. 상단에서 양손 각각의 **인식 → Pinch → 잡힘** 상태를 확인할 수 있습니다. 예제 8~11의 상단 메뉴에서 **12 고무 인간** 버튼으로 들어올 수 있고, 12번 상단 메뉴에서도 다른 예제로 이동할 수 있습니다. 기존 예제에는 메뉴 링크만 추가했으며 화면 디자인과 인터랙션 코드는 유지합니다.

카메라를 끄거나 권한이 거부되면 같은 예제 화면에 **카메라 다시 연결** 버튼을 표시합니다. 브라우저가 사용자 클릭을 요구할 때도 이 버튼으로 다시 연결할 수 있습니다. 소개 화면과 캐릭터 대기 애니메이션으로 돌아가지 않습니다.

카메라는 여백·둥근 프레임·하단 푸터 없이 화면 전체를 채웁니다. 예제 메뉴와 상태, 조작 버튼만 영상 위에 표시합니다. 왼손·오른손의 인식 상태와 전체 얼굴 랜드마크 개수를 각각 확인할 수 있습니다.

## 구현

- 기존 `shared/HandDetector`와 루트의 로컬 손 모델·WASM·폰트를 읽기 전용으로 공유합니다.
- 별도 CPU Worker에서 자르지 않은 640px 입력으로 전체 얼굴의 최대 478개 랜드마크를 최대 20fps로 추적하고, 짧은 시간 필터로 흔들림을 줄입니다. 손 추적은 최대 30fps, 화면은 최대 60fps이며 한 모델당 동시에 한 프레임만 처리합니다. 기존 두 손 모델을 유지하여 왼손·오른손을 동시에 처리합니다.
- Pinch는 실제 영상의 엄지·검지 간격과 3D 거리 중 안정적인 값을 손바닥 크기로 정규화해 판정합니다. 얼굴 앞에서 3D 깊이 추정이 흔들려도 화면에서 손끝이 맞닿으면 잡기가 가능합니다. 최초 Pinch 프레임뿐 아니라 유지 중에도 얼굴 접촉을 검사합니다. 손이 얼굴을 가릴 때는 마지막 확인된 얼굴을 최대 6초간 유지하여 입력이나 합성을 즉시 차단하지 않습니다.
- 한 손이 화면 가운데를 지나도 같은 추적 ID를 유지합니다. 빈 슬롯이 기존 손보다 우선되어 하나의 손이 두 슬롯으로 복제되거나 잡기가 끊기던 문제를 수정했습니다. 검출 결과가 잠시 비어도 잡은 지점을 약 0.3초 더 유지하며, 손가락을 벌린 결과가 오면 즉시 놓습니다.
- 전체 얼굴 랜드마크를 유지하고, 36개의 윤곽을 주기적 Catmull–Rom 곡선으로 보간해 **25,346개 정점 / 50,336개 삼각형**의 둥근 얼굴과 연결 메시를 만듭니다. 기존 외곽 집기 제한과 얼굴 텍스처를 피부색으로 치환하던 처리를 제거했습니다. 양손은 가까운 두 얼굴 지점도 각각 정확히 잡으며, 두 Gaussian 변형장을 함께 풀어 각 재질 좌표를 자신의 손끝에 고정합니다.
- 한 손의 손목 회전, 양손의 상대 각도·손목 회전·벌리는 거리를 누적하여 높이에 따른 3D 비틀림을 만듭니다. 비틀릴수록 길어지는 축과 부드러운 부풀음, 피부색 뒷면, 표면 법선에 따른 조명으로 얇은 종잇장 대신 둥근 고무의 두께와 주름을 표현합니다. 깊이 검사로 겹치는 표면을 처리합니다. 놓으면 손의 이동 관성을 이어받은 감쇠 스프링으로 복원됩니다.
- 평상시에는 마스크나 얼굴 메시를 합성하지 않고 **원본 카메라를 그대로** 보여 줍니다. 늘어나거나 꼬인 동안에만 원래 눈·코·입을 두 볼 주변의 평균 피부색으로 불투명하게 덮습니다. 가장자리는 부드럽게 페더링하고 변형이 사라지면 덮개도 함께 사라져 타원형 외곽 경계가 남지 않습니다. 카메라 프레임 가이드 선도 제거했습니다.
- 얼굴 바깥에 22%의 연결 영역을 추가하고 바깥 끝의 위치와 기울기가 원본 영상에 자연스럽게 이어지게 고정합니다. 큰 변형에서는 닫힌 입체 얼굴을 표시하고, 복귀하면서 변형이 작아지면 연결 영역을 부드럽게 합성합니다. 주변 영상이 큰 비틀림에 함께 접히지 않게 분리합니다. 얼굴이 손에 가릴 때는 얼굴 텍스처만 유지하고, 연결 영역은 별도 실시간 카메라 텍스처로 계속 갱신합니다. 전체 얼굴 앞면을 그대로 보존하며 피부색은 원래 이목구비를 가리는 덮개와 꼬임의 뒷면에만 사용합니다.
- 복귀 시에는 변위뿐 아니라 속도를 포함한 스프링 에너지로 합성을 감쇠합니다. 중립 위치를 통과하는 순간 얼굴이 꺼졌다 켜지지 않으며, 미세 진동까지 연속적으로 줄인 뒤 원본 카메라로 이어집니다. 짧은 얼굴 가림은 즉시 메시를 초기화하지 않고 손잡기를 해제해 부드럽게 복귀시킨 뒤 필요하면 서서히 숨깁니다.
- 탭 숨김·크기 변경 시 추적 좌표를 초기화하며, 종료·페이지 이동 시 카메라 트랙과 Worker를 정리합니다. 카메라 영상은 저장·전송하지 않습니다.

얼굴 Worker는 MediaPipe의 `importScripts`와 호환되는 classic bundle을 포함합니다. 소스를 바꿨다면 다음 명령으로 다시 생성합니다. 서버는 실행하지 않습니다.

```sh
node example-12/scripts/build-face-worker.mjs
node --test example-12/tests/*.test.ts
npm run build
```
