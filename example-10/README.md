# Jelly Black Hole · Example 10

왼손의 ㄴ과 오른손의 ㄱ 사이에 열리는 도트 우주입니다. 두 손이 만드는 빈 공간이 블랙홀의 위치와 크기를 결정합니다.

루트 `interactive_artwork`에서 사용자가 개발 서버를 실행합니다.

```sh
npm run dev
```

주소: **https://localhost:5174/example-10/**

예제 8·9의 인터랙션은 유지하고 상단에 10번 선택 항목을 추가했습니다. 기본 주소 `https://localhost:5174/`에서도 10번으로 이동하며, 세 예제 모두 상단에서 다른 예제로 이동할 수 있습니다. 카메라 영상은 저장하거나 전송하지 않고, 기존 공통 Worker와 로컬 MediaPipe 모델을 사용합니다.

## 사용 방법

1. **카메라로 우주 열기**를 누르고 카메라 접근을 허용합니다.
2. 엄지와 검지만 펴고 나머지 손가락은 접습니다. 화면을 보며 왼손의 두 손가락은 **위쪽·오른쪽**인 ㄴ, 오른손은 **아래쪽·왼쪽**인 ㄱ으로 만듭니다. 엄지와 검지 중 어느 손가락이 세로 방향이어도 됩니다. 예를 들어 오른손은 검지를 왼쪽, 엄지를 아래로 향해도 인식합니다. 왼손 모서리는 왼쪽 아래, 오른손 모서리는 오른쪽 위에 두고, 두 손가락 쌍이 하나의 빈 사각형을 감싸도록 정렬합니다.
3. 정렬을 약 0.18초 유지하면 두 손 사이에 블랙홀이 생깁니다. 양손을 움직이면 따라오고, 가로 간격을 넓히거나 좁히면 늘어나거나 작아집니다. 손가락이 감싼 공간을 벗어나지 않도록 타원으로 변형됩니다.
4. 약 2초간 모양을 유지하면 젤리·캔디·구미·말랑한 덩어리 32개가 쏟아집니다. 계속 유지하면 약 3.2초마다 다시 쏟아집니다. 일부는 중력과 탄성으로 튀고 떨어지며, 일부는 블랙홀 주변을 떠다닙니다.
5. 손 모양을 풀거나 한 손을 화면 밖으로 빼면 블랙홀이 오므라든 뒤 POP! 효과와 별가루를 남기고 사라집니다.

하단에서 다시 시작, 손 표시, 소리, 카메라 종료를 조작합니다. 소리는 카메라 시작 버튼을 누른 뒤에만 준비하며, 오디오를 지원하지 않아도 시각적 인터랙션은 사용할 수 있습니다.

## 구현과 성능

- 엄지·검지의 펼침과 직각, 나머지 손가락의 접힘, 화면상의 ㄴ·ㄱ 방향·정렬·신뢰도를 함께 검사합니다. 카메라의 좌우 손 라벨에 의존하지 않으며, 세로·가로 손가락의 역할이 바뀌어도 같은 모양으로 인식합니다. 3D 관절을 사용할 수 있으면 원근 때문에 화면에서 손가락이 겹쳐 보이는 경우도 구분합니다. 손바닥 중심 대신 엄지와 검지 축의 교점을 사용합니다. 제스처가 풀리거나 추적이 250ms 이상 중단되면 유지 시간을 취소합니다.
- 안내에는 손 인식 수와 왼쪽 ㄴ·오른쪽 ㄱ의 통과 여부를 표시합니다. 조건을 충족하지 못하면 검지 펴기, 엄지 벌리기, 나머지 손가락 접기, 방향과 정렬 중 필요한 동작을 구체적으로 안내합니다.
- 입력 좌표와 카메라에 같은 좌우 반전·화면 채움 변환을 적용합니다. 창 크기 변경, 탭 전환, 초기화 뒤에는 이전 비동기 추적 결과를 반영하지 않습니다.
- Canvas 2D의 낮은 해상도 버퍼와 `image-rendering: pixelated`로 도트 스타일을 그립니다. 외부 이미지·폰트 서비스·그래픽 라이브러리를 추가하지 않습니다. 픽셀 스프라이트는 한 번 생성해 재사용합니다.
- 공통 렌더 루프의 최대 60fps, 손 추적 최대 30fps와 단일 추론 처리를 사용합니다. 젤리는 최대 100개, 별가루는 최대 200개로 제한하며 물리는 1/120초 단위로 계산합니다.
- 숨겨진 탭에서 렌더링·영상·소리를 중지하고, 카메라 종료·페이지 이동 시 인식 Worker, 미디어 트랙과 오디오를 정리합니다. 동작 줄이기 설정에서는 공간 오브젝트의 이동·흡입과 테두리 출렁임을 줄이고 방출 수를 12개로 낮춥니다.

## 검증

```sh
npm --prefix example-10 test
npm test
npm run build
```

검증 도구는 개발·미리보기 서버를 실행하지 않습니다. 제스처 검사·유지 시간·추적 중단·이동·크기 변화, 중력·반발·궤도 운동, 장면의 방출 수 제한과 소멸 이벤트를 서버 없이 검사합니다. 실제 카메라 인식률과 브라우저별 화면은 실기기 확인이 필요합니다.
