# PUPPET SHOW · Example 11

왼손으로 Christine 목각 마리오네트를 걷게 하고 연기하며, 오른손 지휘봉으로 **Twinkle, Twinkle, Little Star**를 부르는 1인 인형극입니다. 공식 영상 플레이어·곡 선택·음원 업로드·피치 변조 기능은 제거했습니다. 메인 페이지와 다른 예제는 수정하지 않습니다.

주소: **https://localhost:5174/example-11/**

개발 서버는 사용자가 프로젝트 루트에서 `npm run dev`로 실행합니다. 에이전트는 개발·미리보기 서버를 실행하지 않습니다.

## 시작과 안내

딥 레드 브라운 벨벳 커튼 앞에는 짙은 마호가니 바탕과 앤티크 골드 조각 프레임의 극장 명판을 매답니다. 금빛 체인으로 연결하고 올드 스타일 디스플레이 서체 Rye를 따뜻한 골드로 배치합니다. 입체적인 앤티크 올리브·브론즈 조각 프레임, 세 겹의 진홍색 벨벳 드레이프, 금색 프린지·태슬과 무대 앞단은 투명 PNG 전경으로 구성합니다. 중앙 무대는 실제 알파로 비워 퍼펫·카메라·이동 커튼과 분리하고, 뒤쪽의 금빛 패널 벽과 월넛 바닥에 따뜻한 조명을 겹칩니다. 간판 하강·상승, 박수치는 목각 관객, 핀 조명·스탠드 마이크는 유지합니다. 시작 버튼은 중앙 하단의 붉은 필름 스트립입니다. 실제로 뚫린 위아래 퍼포레이션, 어두운 필름 프레임과 작은 재생 아이콘을 사용하며 호버·클릭 시 부드럽게 반응합니다. 공연 중 버튼은 읽기 쉬운 아이보리·황동 스위치, 악보는 아이보리 인쇄 종이로 통일합니다. 왼손·오른손 상태에는 각각 인형 조종과 노래 지휘 역할을 표시하고, 주요 버튼은 노래 에코·소리·노래 다시·공연 안내·막 내리기로 묶습니다. 인형 줄 맞춤과 손 관절 보기는 별도의 조종 설정 메뉴에 남깁니다. 예제 전환 메뉴는 변경하지 않습니다.

**공연 시작**을 누르면 방문 이력과 관계없이 **공연 전 관람 안내**를 먼저 엽니다. 버건디 배경 위의 크림색 레이스 종이에 짙은 갈색 잉크, 큰 한글 제목과 13~14px 본문을 사용합니다. 종이 질감과 레이스가 글 위에 겹치지 않게 여백을 두고 회전을 없앴습니다. 본문은 별도로 스크롤하며 공연 시작 버튼은 계속 보입니다. 안내에서 **공연 시작**을 눌러야 카메라·오디오가 준비됩니다. 공연 중 안내를 열면 음악이 현재 위치에서 쉬고, 닫은 뒤 다시 지휘하면 이어집니다. Esc로 안내를 닫을 수 있습니다.

무대 뒤는 푸른 회색 유리, 금빛 창살, 아치 천장과 따뜻한 펜던트 조명이 있는 유리 홀입니다. 얼굴 영상은 창문 안쪽에만 부드럽게 비칩니다. 같은 원본 영상을 MediaPipe BlazeFace CPU Worker에서 최대 8fps·320px 입력·한 프레임씩 처리하고, 얼굴 바운딩 박스 안의 타원 마스크만 표시합니다. 좌우 반전과 cover 좌표가 영상과 마스크에 함께 적용됩니다. 얼굴이 없거나 결과가 300ms 이상 오래되면 감춥니다. 얼굴 Worker나 CSS 마스크 미지원 때도 방 전체 화면을 대신 보여주지 않습니다.

양손은 이미 추적한 21개 관절을 기준으로 최대 768px 크기의 작은 캔버스 두 장 안에서만 카메라를 잘라 28% 불투명도로 비춥니다. 왼손에는 목재 십자 조종대와 다섯 고리·실, 오른손에는 조각 무늬 손잡이와 붉은 보석이 달린 지휘봉을 겹칩니다. 손·도구 좌표는 같은 화면 좌표를 사용하며 커튼 장식 앞에서도 보입니다. 같은 영상 프레임과 관절 좌표에서는 다시 그리지 않고, 손을 잃거나 공연을 닫으면 숨깁니다. 별도 영상 스트림이나 손 검출 모델은 추가하지 않습니다.

얼굴과 손은 픽셀별 세그멘테이션이 아니라 타원 크롭이므로 부드러운 경계에 소량의 주변 화소가 포함될 수 있습니다. 영상은 기기 안에서만 처리하며 녹화·업로드하지 않습니다. 모델과 구성은 [FACE-SOURCES.md](FACE-SOURCES.md)에 기록했습니다.

## 왼손: MOVE & POSE

왼손을 좌우로 옮기면 몸의 이동 거리로 걸음 주기를 계산합니다. 한쪽 발이 공중에서 앞으로 나갈 때 반대쪽 발은 바닥의 같은 위치에 고정합니다. 발이 바닥에 닿으면 다음 발이 움직이고, 멈추면 두 발이 부드럽게 내려옵니다. 인형 전체만 평행 이동시키는 방식이 아닙니다.

손끝은 다음 공연 채널을 조종합니다.

| 손가락 | 조작 |
| --- | --- |
| 엄지 | 왼팔 들어 올리기·벌리기 |
| 검지 | 오른팔 들어 올리기·벌리기 |
| 중지 | 고개 기울이기 |
| 약지 | 몸을 젖히는 공연 자세 |
| 새끼 | 무릎을 살짝 굽히는 자세 |

팔꿈치·무릎은 길이가 고정된 두 뼈로 움직입니다. 머리는 목을 회전축으로 사용하고, 목·코르셋·한 장의 치마는 연결을 유지합니다. 상체를 짧게 조정하고 코르셋 파츠를 원래 가로세로 비율에 가깝게 그립니다. 목 하단은 드레스 목선 뒤로 들어가도록 그리기 순서를 정리했으며, 걸을 때 치마 전체가 커튼 안쪽에 머물도록 이동 범위를 제한합니다. 실은 다섯 손끝과 목재 조종대의 고리를 거쳐 각 제어 지점까지 이어지며 당김에 따라 처짐과 밝기가 달라집니다. 발걸음을 볼 수 있도록 치마는 같은 레이스 파츠의 가로세로 비율을 유지한 채 발목 위로 배치합니다.

손을 멈추거나 잠시 잃어도 마지막 포즈를 유지합니다. 다시 잡힐 때 현재 포즈를 기준으로 손을 맞춰 갑자기 중립 자세로 돌아가지 않습니다. **줄 맞추기**로 현재 손 자세를 기준으로 삼습니다. 표정과 입 모양은 노래에서 별도로 계산해 왼손 연기와 함께 사용할 수 있습니다.

## 오른손: CONDUCT & SING / VOLUME

오른손 검지 방향으로 지휘봉을 그립니다. 좌우의 충분한 움직임이 감지되는 동안 원래 선율을 **84 BPM**으로 진행합니다. 멈추면 약 160ms의 움직임 유예 후 보컬과 반주가 쉬고, 음표 번호·음표 안의 진행률·가사 모음·악보 커서가 같은 위치를 유지합니다. 다시 흔들면 그 위치부터 이어갑니다. 작은 떨림과 위아래 볼륨 조작만으로 노래가 시작되지 않도록 문턱값을 둡니다.

높이는 **보컬 볼륨만** 바꿉니다. 위는 크게, 아래는 작게 부릅니다. 원곡의 음정·선율은 손 높이에 영향을 받지 않으며 반주 게인은 일정합니다. 소리 토글을 끄면 진행도 쉬고, 다시 켠 뒤 지휘하면 이어집니다. 손 검출 누락과 재검출, 안내 열기, 탭 숨김 뒤에 시간이 누적되어 노래가 건너뛰지 않습니다.

## 새로 합성하는 음악과 모음 보컬

원곡의 42개 음표·48박을 사용하며 연속 지휘 시 **약 34.3초**입니다. 퍼블릭 도메인 선율의 근거는 [MUSIC-SOURCES.md](MUSIC-SOURCES.md)에 기록했습니다. 녹음 파일·외부 스트림·음원 샘플·Tone.js 없이 Web Audio API로 새로 합성합니다.

피아노풍 삼각파 아르페지오, 낮은 현악 패드, 가벼운 오르골 배음을 별도 반주 경로로 만듭니다. 보컬은 풍부한 성대 배음에 세 개의 모음 공명 필터, 호흡 성분, 비브라토와 약한 기계적 변조를 더합니다. 각 영어 음절의 모음(ih/uh/ah/oh/oo/er)을 원곡 선율에 맞춰 발성합니다. 가사 발음은 모음 중심의 레트로 사이버 오페라 합성입니다.

음악 시계는 AudioContext의 시간을 사용합니다. 같은 `MusicState`가 실제 음높이·모음·볼륨·음절 강약·입 모양·악보를 구동합니다. 고음에서는 입이 더 크게 열리고 고개가 살짝 들립니다. **마이크 에코 ON/OFF**는 보컬에만 적용하며 사용자 마이크 권한을 요청하지 않습니다. 반주는 에코를 우회합니다. 정지할 때 음성 게이트는 짧게 감쇠하고 에코의 자연스러운 잔향은 남습니다.

## 실제 멜로디 악보와 작은 상태 표시

오른쪽에는 실제 Twinkle 멜로디의 음표·박자·음절을 그립니다. 음표 머리는 붉은 하트 모양이며 4분음표는 채우고 2분음표는 비워 박자 구분을 유지합니다. 현재/지난/앞으로 부를 음표의 색과 진행 커서는 같은 음악 상태에 연결됩니다. 마이크는 금빛 수평 그릴과 둥근 바닥 받침이 있는 세로형 빈티지 스탠드입니다. 무대 크기에 따른 고정 좌표로 그리며 인형의 이동·고개·포즈를 따라가지 않습니다. 작은 카드에서는 현재 한두 악구씩 화면 폭에 맞춰 자동으로 넘기고, 확대하면 여섯 악구 전체를 봅니다. 현재 음표를 강조하고 음표 안의 위치도 표시합니다. 정지하면 커서와 강조 위치도 멈춥니다. 클릭과 Esc 확대·축소 동작은 유지합니다.

하단은 양손 인식 상태, 지휘 상태, 보컬 볼륨 게이지와 필요한 버튼만 남깁니다. 공연 중 안내는 다시 열 수 있습니다. **다시 노래**는 음악만 처음으로 돌리고 현재 인형 포즈는 유지합니다.

## 막 내리기와 The End

**막 내리기**를 누르면 카메라 트랙·추론·오디오를 즉시 종료하고 약 0.8초 동안 커튼을 닫습니다. 커튼이 닫힌 뒤 아이보리 레이스 하트와 Great Vibes 필기체 **The End**가 나타납니다. 약 0.8초 후부터 2.8초 동안 커튼·무대 프레임·엔딩 카드가 함께 흑백으로 바뀝니다. **다시 공연**은 색을 복원하고 새 카메라 세션으로 시작하며, **처음으로**나 Esc는 간판 화면으로 돌아갑니다. 엔딩에 별도 오디오나 카메라를 유지하지 않습니다.

안내와 엔딩은 키보드 초점을 안쪽에 유지하고, 닫으면 해당 버튼에 돌려줍니다. 모션 감소 설정에서는 엔딩 등장·흑백 전환을 즉시 적용합니다. Rye와 Great Vibes는 Google Fonts의 SIL OFL 글꼴을 예제 안에 저장해 외부 폰트 요청 없이 사용합니다. 생성 목재 파일과 제작 프롬프트는 [assets/GENERATION.md](src/assets/GENERATION.md)에 기록했습니다.

## 성능과 검증

MediaPipe의 기존 Worker, 좌우 손 배정과 관절 안정화는 유지합니다. 새 영상 프레임에만 최대 30회/초 추론하고 동시에 한 프레임만 처리합니다. 렌더링은 공통 최대 60fps 루프를 사용합니다. 바닥·파츠 경계는 캐시하며 사용하지 않는 핑크 의상은 로딩하지 않습니다. 같은 음표·볼륨이 유지되면 오디오 노드나 자동화 이벤트를 계속 추가하지 않습니다. 숨겨진 탭에서는 영상·오디오·렌더링을 쉬고 페이지 이동 시 모두 해제합니다.

```sh
npm --prefix example-11 run build:face-worker  # 얼굴 Worker 소스를 바꾼 경우
npm --prefix example-11 test
npm test
npm run build
```

검사는 선율·음절·길이, 지휘/정지/재개, 지터·누락·배경 복귀, 높이와 음정 분리, 보컬/반주 라우팅·에코·해제, 다섯 포즈 채널, 발 접지와 관절 길이, 실제 악보 그리기를 포함합니다. 서버 없이 로컬 파일을 연 브라우저에서 정적 UI와 OfflineAudioContext 합성도 확인합니다. 실제 웹캠을 앞에 둔 손동작과 기기별 오디오 청감은 사용자 환경에서 확인해야 합니다.

실제 main 스크립트를 임시 정적 파일로 번들링하고 카메라·MediaPipe 출력만 합성 입력으로 대체한 브라우저 검사도 수행했습니다. 첫 안내, 지휘 재생, 정지 위치 유지, 위아래 볼륨만 변경, 안내 중 동결·재개, 에코·악보 토글, 종료 시 트랙 해제, 하트 엔딩·흑백 전환, 다시 공연과 처음으로 복귀를 확인했습니다. 데스크톱·모바일의 안내·간판·공연·엔딩 배치를 로컬 파일 브라우저로 확인했습니다. 개발·미리보기 서버는 실행하지 않았습니다. OfflineAudioContext로 전체 42음을 렌더링한 결과 최대 진폭은 약 0.505(클리핑 없음)였습니다.

얼굴 검출 소스는 `src/face-worker.ts`, 재현 빌드는 `scripts/build-face-worker.mjs`에 있습니다. 예제 안의 `src/assets/face-runtime/face-worker.js`는 미리 빌드한 classic Worker라 루트 빌드 설정이나 다른 예제를 수정하지 않습니다. 얼굴 모델 실패·누락·크기 변경·중단과 재개, 마스크 좌표, 프레임 중복 방지, 포획 중 종료를 자동 검사합니다. 서버 없이 실제 모델/WASM을 Worker에서 초기화해 퍼펫 얼굴 이미지에서는 얼굴 박스가 나오고 빈 화면에서는 나오지 않는 것까지 확인했습니다. 실제 main 스크립트의 합성 카메라·손 입력 검사에서도 안내·음악·엔딩 흐름이 통과했습니다. 실제 웹캠 얼굴과 인앱 브라우저별 동작은 사용자 기기에서 확인해야 합니다.

박수치는 목각 관객은 무대 앞단에 가려졌던 높이를 올려 손바닥이 보이도록 했습니다. 손목 끝은 앞단 뒤에 남아 공중에 잘린 손처럼 보이지 않게 배치합니다. 관객 수, 서로 다른 박수 타이밍, 박수·환호와 등장·퇴장 순서는 유지합니다. 자동 검사는 손바닥/손목의 앞단 관계, 조종대 다섯 고리의 손 좌표 추종, 카메라 크롭 좌표·불투명도·마스크와 캔버스 크기 상한·같은 프레임 중복 방지까지 포함합니다. 실제 main 브라우저 검사에서 조종 설정 열기, 줄 맞춤과 관절 표시, 양손 도구 등장·종료 시 숨김도 확인했습니다.
