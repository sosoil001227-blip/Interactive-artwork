# magic · Example 09

카메라 영상 위에서 양손으로 마법진을 만들고 앞으로 보내는 실험입니다.

`interactive_artwork` 폴더에서 실행합니다.

```sh
npm install  # 최초 설치 시에만
npm run https:cert  # 최초 설정 또는 IP 변경 시
npm run https:trust # CA 신뢰 등록
npm run dev
```

주소: **https://localhost:5174/example-9/**. 같은 서버의 상단 버튼으로 8번 WaterTouch와 전환할 수 있습니다.

1. **카메라 켜고 시작하기**를 누르고 카메라 접근을 허용하세요.
2. 양손을 카메라에 보이고, 손가락을 편 상태에서 손바닥을 서로 마주 보게 하세요. 두 손 사이에 마법진이 생기며 신비로운 종소리와 은은한 잔향이 한 번 재생됩니다.
3. 두 손을 좌우로 천천히 벌리면 마법진이 커집니다.
4. 넓힌 상태에서 손가락을 까딱이면 형광빛 마법진이 떨리며 낮은 웅웅 소리가 납니다. 움직임이 클수록 떨림과 빛, 소리가 강해지고 멈추면 서서히 가라앉습니다.
5. 손을 벌린 상태를 유지하며 **양쪽 손바닥을 카메라 쪽으로** 돌리면 마법진이 앞으로 뻗어나갑니다.
6. 다시 발사하려면 손바닥을 서로 마주 보는 단계부터 시작하세요.

손목부터 모든 손가락까지 양손 42개 관절과 손바닥을 추적합니다. 어두운 곳이나 손이 서로 가려지는 자세에서는 인식이 불안정할 수 있습니다. 손가락이 보이도록 약간 비스듬히 마주 보는 자세도 허용합니다.

화면 하단에는 반투명 안내와 작은 조작 바만 표시합니다. 소리 ON/OFF, 손 추적 표시 및 인식 수치는 **설정**을 눌러 확인하세요. 설정은 바깥 클릭이나 Esc로 닫을 수 있습니다. 조작 바의 되돌리기 버튼은 마법진을 초기화하고, 종료 버튼은 카메라를 끕니다. 카메라 영상은 저장하거나 전송하지 않습니다. MediaPipe WASM과 모델도 설치 시 내려받아 로컬 서버에서 제공합니다.

## 구현

- [MediaPipe Hand Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/web_js), `VIDEO`, `numHands: 2`. GPU 초기화 실패 시 CPU로 전환합니다.
- 손바닥 중심은 손목·MCP 관절 `0, 5, 9, 13, 17`의 평균입니다. 3D 좌표로 손바닥의 부호 있는 법선을 계산하고 handedness로 방향을 보정하여 손등과 손바닥을 구분합니다.
- 펼친 손가락 수, 손바닥 방향, 가로 간격 및 유지 시간을 조합하는 상태 머신: `gather → grow → ready → cast`. 순간 자세 변화, 프레임 중단, 한 손 검출만으로는 발사되지 않습니다.
- 가로 간격에 비례하는 마법진 반경, 회전하는 룬·기하학 패턴·빛 입자, 원근 확대와 잔상으로 표현하는 전방 발사 효과. Canvas 2D로 직접 그리며 외부 이미지나 폰트 서비스에 의존하지 않습니다.
- 카메라와 좌표에 동일한 좌우 반전·화면 채움 변환을 적용합니다. 창 크기 변경과 백그라운드 전환은 제스처를 초기화합니다.
- 손바닥의 로컬 3D 좌표계에서 정규화한 손끝 변화량을 측정하여 손 전체의 이동·회전과 손가락 움직임을 구분합니다. 추적 중단이나 재검출은 진동 충격을 만들지 않습니다.
- 형광빛 번짐은 미리 그린 광채 레이어를 합성합니다. 손가락 움직임에 비례해 미세 진동, 맥동과 빛 입자가 반응합니다.
- 생성 효과음은 상승하는 종소리, 반짝이는 배음과 잔향을 Web Audio로 합성합니다. 새 마법진을 만들 때 한 번만 재생하며 유지·확대 중에는 반복하지 않습니다. 소리 OFF와 카메라 종료는 효과음 및 잔향도 중단합니다.
- Web Audio로 낮은 진동음을 합성하며 카메라 시작 버튼을 누른 뒤에만 오디오를 준비합니다. 손가락이 멈추면 소리가 잦아들고 소리 OFF·카메라 종료·페이지 이동 시 종료됩니다.
- 카메라 끄기와 페이지 이동 시 미디어 트랙을 종료합니다. 동작 줄이기 설정에서는 진동과 확산 링을 줄입니다.

검증:

```sh
npm --prefix example-9 test
npm run build:example9
```

결과물: `interactive_artwork/dist/`. 8번과 9번을 하나의 5174 서버에서 실행합니다. 상단 버튼으로 예제를 바꾸면 이전 카메라를 종료합니다. 루트 `npm run dev` 하나만 실행하면 됩니다.

로컬 네트워크 HTTPS 설정과 다른 PC의 인증서·카메라 권한 안내: [HTTPS 접속 안내](../docs/HTTPS.md). 현재 공유 주소는 **https://172.30.1.95:5174/example-9/** 입니다.
